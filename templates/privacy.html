Privacy Policy

Effective Date: September 26, 2026

1. Our Core Privacy Commitment

At ToolHub, privacy is not an afterthought — it is our primary design principle. We believe user data belong exclusively to the user.

2. Local Browser Processing

The vast majority of tools on ToolHub (including JSON Formatter, Base64 Converter, Image Compressor, Password Generator, Hash Generator, and Calculators) run 100% locally inside your web browser using HTML5, JavaScript, and Web Crypto APIs. Input data, uploaded images, and calculated values never leave your device.

3. No File Storage & Temporary Cleanup

For tools requiring optional server-side processing, uploaded files are processed in ephemeral memory buffers and immediately discarded upon response completion. We do NOT permanently store user uploaded files or log file contents.

4. Analytics & Tracking

ToolHub does NOT use invasive third-party tracking scripts, cross-site profiling cookies, or persistent identity trackers.

5. Local Storage & Preferences

We use browser localStorage solely to save your dark/light theme choice, your bookmarked favorite tools, and your recently used tools list.
