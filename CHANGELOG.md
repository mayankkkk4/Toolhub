# Changelog

All notable changes to the **ToolHub** platform will be documented in this file.

## [1.0.0] - 2026-09-26

### Added
- Centralized Python Tool Registry with 40+ tool definitions across 8 categories.
- Client-side browser execution engine for JSON Formatter, Base64, URL Encoder, JWT Decoder, UUID Generator, Regex, Timestamp, Color Converter, Code Formatters, Markdown Editor.
- Text suite: Word Counter, Case Converter, Remove Duplicate Lines, Sort Lines, Find & Replace, Text Diff, Lorem Ipsum Generator.
- Calculators & Converters: Scientific Calculator, Universal Unit Converter, Percentage, Age, Date Difference, BMI.
- Image suite: Compressor, Resizer, Format Converter, Cropper, Metadata/EXIF viewer.
- Security & Privacy suite: Cryptographic Password Generator, Password Strength Analyzer, Web Crypto Hash Generator, Local File Checksum, URL Safety Inspector.
- Extensible AI Service pipeline for Summarization, Rewriting, Explanations, and Quiz Generation with rule-based fallback.
- REST API endpoints (`/api/tools`, `/api/categories`, `/api/favorites`, `/api/ai/*`).
- PWA manifest and service worker for offline tool usage.
- Docker & Docker Compose setup.
- Comprehensive pytest test suite.
